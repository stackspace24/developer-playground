# Project Structure

A well-organized project structure makes code easier to maintain and navigate.

## Recommended Directories

- `src/` — Main application source code
- `components/` — Reusable UI components
- `pages/` — Application pages or routes
- `public/` — Static assets
- `styles/` — CSS and styling files
- `utils/` — Helper functions

## Best Practices

1. Keep related files together.
2. Use descriptive file and folder names.
3. Separate reusable components from page-specific code.
4. Avoid placing unrelated logic in a single file.
