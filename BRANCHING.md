# Git Branching Guide

Branches allow developers to work on changes independently without affecting the main branch.

## Branch Naming

Use descriptive names for branches:

- `feature/add-login`
- `fix/navbar-layout`
- `docs/update-readme`

## Basic Workflow

1. Create a new branch from `main`.
2. Make your changes.
3. Commit your changes with a clear message.
4. Open a pull request.
5. Merge the pull request after checking the changes.
